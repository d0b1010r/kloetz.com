# Fonts

Fraunces Black is self-hosted in this subdomain's `/fonts/` directory.
The font is the same build used by `david/`: weight 900, optical sizes 9–144,
softness 100, and wonk 1. Softness and wonk are baked into the font;
CSS automatically selects its optical size.

Source: https://github.com/googlefonts/fraunces
License: `Fraunces-OFL.txt`.

No third-party font requests are made by the page.
