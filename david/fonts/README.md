# Fonts

Self-hosted fonts served from this subdomain's `/fonts/` directory:

- **Fraunces Black** — Google Fonts build requested at weight 900,
  optical sizes 9–144, softness 100, and wonk 1.
  Source: https://github.com/googlefonts/fraunces
  License: `Fraunces-OFL.txt`.
- **Source Sans 3 Regular** — Google Fonts build requested at weight 400.
  Source: https://github.com/adobe-fonts/source-sans
  License: `SourceSans3-OFL.txt`.

The softness and wonk choices are baked into this Fraunces build;
CSS automatically selects its optical size. No third-party font requests
are made by the page.
